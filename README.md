# OAuth Atlas

Evidence-backed setup guides for creating and getting approval for OAuth apps, built for Composio's APM (toolkits) take-home.

Work in progress. Full README lands at the end of Day 1.

## Run locally

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate   macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
```

Keys go in a local `.env` (copy `.env.example`). `.env` is git-ignored and never committed.
